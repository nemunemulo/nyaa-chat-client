====================================================================
  Nyaa Chat Portable - 로컬 대화 기록 저장소 (logs/)
====================================================================

[안내]
settings.ini에서 SaveLogs=true 로 설정되어 있으면,
참여 중인 각 채널의 대화가 [채널명_YYYY-MM-DD.txt] 파일로
이 폴더(logs/)에 실시간 자동 기록됩니다.

서버 대화 기록과 무관하게, 클라이언트 사용자의 PC(이 폴더)에 기록된 텍스트 파일은
사용자가 직접 지우기 전까지 영구 보관됩니다.
