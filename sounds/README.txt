====================================================================
  Nyaa Chat Portable - 사용자 효과음 폴더 (sounds/)
====================================================================

[안내]
클라이언트 기본 배포판에는 용량 경량화 및 저작권/보안 투명성을 위해
어떠한 소리(.wav, .mp3)나 영상 파일도 기본 포함하지 않습니다.

[내 효과음 넣는 방법]
1. 원하시는 효과음 파일(.wav, .mp3, .ogg, .m4a)을 이 폴더(sounds/)에 넣으세요.
2. NyaaChat 클라이언트 상단 바의 [🔊 효과음 설정] 버튼을 클릭하세요.
3. [🔄 폴더 새로고침]을 누르면 방금 넣은 파일이 목록에 자동으로 나타납니다.
4. 호출(멘션) 알림, 일반 메시지 수신, 유저 입장/퇴장 등 상황별로
   원하는 효과음 파일을 지정하고 [저장]을 누르면 즉시 적용됩니다!
