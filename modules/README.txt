==============================================================================
 Nyaa Chat 서버별 선택형 모듈 폴더 안내 (modules/)
==============================================================================

1. 갈라파고스화 방지 및 100% 하위호환 원칙
   - Nyaa Chat의 모든 기본 서버(예: A서버)는 모듈이 전혀 없어도 100% 완벽하게
     대화하고 이용할 수 있는 표준 프로토콜(nyaa-core-v1)로 동작합니다.
   - 특정 서버(예: C서버)에서 전용 봇과 상호작용하는 확장 모듈(예: CCC.txt)을
     제공할 경우, 이 폴더(modules/)에 텍스트 규격 파일로 저장됩니다.

2. 서버별 자동 활성화 & 타 서버 이동 시 자동 비활성화
   - 모듈 파일 안에 지정된 대상 서버(TargetServer)에 접속해 그 서버 창을 보고 있을 때만
     전용 버튼과 확장 명령어가 활성화됩니다.
   - 순정 A서버 창으로 탭을 전환하거나 이동하면 해당 모듈은 즉시 비활성화되어
     타 서버의 기본 환경을 절대 침해하지 않습니다.

3. 보안 원칙
   - 모듈은 오직 눈으로 읽을 수 있는 순수 텍스트 파일(.txt / .ini)만 허용되며,
     기본 표준 명령어(/join, /list, /nick, /help 등)를 덮어쓸 수 없습니다.
