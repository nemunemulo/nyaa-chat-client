==============================================================================
 Nyaa Chat 서버별 선택형 모듈 폴더 안내 (modules/)
==============================================================================

1. 갈라파고스화 방지 및 100% 하위호환 원칙
   - Nyaa Chat의 모든 기본 서버는 모듈이 전혀 없어도 100% 완벽하게
     대화하고 이용할 수 있는 표준 프로토콜(nyaa-core-v1)로 동작합니다.
   - 특정 서버에서 전용 봇과 상호작용하는 확장 모듈(예: CCC.txt)을
     제공할 경우, 이 폴더(modules/)에 텍스트 규격 파일로 저장됩니다.

2. 서버별 자동 활성화 & 타 서버 이동 시 자동 비활성화
   - 모듈 파일 안에 지정된 대상 서버(TargetServer)에 접속해 그 서버 창을 보고 있을 때만
     전용 버튼과 확장 명령어가 활성화됩니다.
   - 다른 서버 창으로 탭을 전환하거나 이동하면 해당 모듈은 즉시 비활성화되어
     타 서버의 기본 환경을 절대 침해하지 않습니다.

3. 플랫폼 호환성 라벨 (Platform=)
   - 모듈 헤더 [Module] 섹션에 'Platform=' 라벨을 지정하여 다기종 간 충돌을 방지합니다.
   - 지원 값:
     * Platform=all (기본값) : 윈도우 GUI, 리눅스 TUI, 안드로이드 Web 모두 동작 (채팅 매크로/봇 버튼)
     * Platform=windows     : 윈도우 전용 (PowerShell 콘솔, Win32 전용 실행 등)
     * Platform=linux       : 리눅스/ARM 콘솔 전용 (bash, htop, tmux 스크립트 등)
     * Platform=web         : 웹/안드로이드 PWA 전용
   - 현재 실행 중인 기기 환경과 맞지 않는 모듈은 에러 없이 조용히 무시(Ignore)됩니다.

4. 플랫폼별 UI 매핑 규격
   - [Buttons] 섹션의 버튼은 각 플랫폼에 맞게 자동 렌더링됩니다:
     * Windows GUI : 상단/하단 툴바 버튼 바
     * Linux TUI   : 하단 펑션 핫키 툴바 ([F1] 버튼명 [F2] ...)
     * Android Web : 입력창 상단 터치 칩(가로 스크롤 버튼)

5. 보안 원칙
   - 모듈은 오직 눈으로 읽을 수 있는 순수 텍스트 파일(.txt / .ini)만 허용되며,
     기본 표준 명령어(/join, /list, /nick, /help 등)를 덮어쓸 수 없습니다.
