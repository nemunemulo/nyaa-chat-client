 Nyaa Chat 서버별 선택형 모듈 안내 (modules/)
==============================================================================

1. 모듈 개요
   - 기본 서버는 모듈 없이도 대화 및 기본 기능을 온전히 이용할 수 있습니다.
   - 특정 서버 전용 봇 상호작용이나 단축 버튼이 필요한 경우, 이 폴더(modules/)에
     텍스트 설정 파일(.txt) 형태로 보관됩니다.

2. 서버별 모듈 연동
   - 모듈 파일 내 TargetServer에 지정된 서버에 접속해 해당 창을 보고 있을 때만
     전용 버튼과 명령어가 활성화됩니다.
   - 다른 서버 창으로 전환하면 해당 모듈은 자동으로 비활성화됩니다.

3. 플랫폼 호환성 (Platform=)
   - 모듈 헤더 [Module] 섹션의 Platform 항목으로 대상 기기를 지정할 수 있습니다:
     * Platform=all (기본값) : 전 플랫폼 호환 (채팅 매크로/봇 버튼)
     * Platform=windows     : 윈도우 전용 (PowerShell 콘솔 등)
     * Platform=linux       : 리눅스 콘솔 전용
     * Platform=web         : 웹/모바일 전용
   - 현재 기기 환경과 맞지 않는 모듈은 자동으로 건너뜁니다.

4. UI 표시 방식
   - [Buttons] 섹션의 버튼은 각 클라이언트 환경에 맞게 자동 렌더링됩니다:
     * Windows GUI : 상단/하단 툴바 버튼 바
     * Linux TUI   : 하단 펑션 키 툴바 ([F1] 버튼명 [F2] ...)
     * Web         : 입력창 상단 터치 버튼

5. 기본 명령어 보호
   - 모듈은 텍스트 설정 파일로만 동작하며, 기본 표준 명령어(/join, /nick, /help 등)는
     임의로 덮어쓸 수 없습니다.
