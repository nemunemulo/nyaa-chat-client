# ============================================================================
# Nyaa Chat 단축 명령어 설정 파일 (aliases.txt - mIRC Aliases 스타일)
# ============================================================================
# [사용법]
#   /단축명령어 = 실행할 메시지 또는 명령어
#
# [사용 가능한 특수 변수]
#   $me          : 현재 내 닉네임
#   $chan        : 현재 접속 중인 채널 이름 (예: #자유대화)
#   $time        : 현재 시각 (예: 21:30:00)
#   $1           : 명령어 뒤에 적은 첫 번째 단어 (예: /커피 철수 -> $1은 철수)
#   $2           : 명령어 뒤에 적은 두 번째 단어
#   $1-          : 명령어 뒤에 적은 모든 문장 전체
#   $rand(1,100) : 1부터 100 사이의 무작위 랜덤 숫자 생성
# ============================================================================

/인사 = 안녕하세요! $chan 채널 여러분 반갑습니다 🐾
/퇴근 = 오늘 하루도 수고 많으셨습니다! 이만 퇴근해 보겠습니다 👋
/주사위 = /me 님이 주사위를 굴려 🎲 [$rand(1,100)] 점이 나왔습니다! (1~100)
/동전 = /me 님이 동전을 던졌더니 🪙 [$rand(1,2)] (1:앞면 / 2:뒷면)이 나왔습니다!
/커피 = /me 님이 $1 님에게 향긋하고 따뜻한 아메리카노를 건넵니다 ☕
/응원 = /me 님이 $1 님을 온 마음을 다해 열렬히 응원합니다!! 🙌✨
/자리비움 = /me 님은 지금 잠시 자리비움 중입니다. ($1-)
/청소 = /clear
/버전 = /me 님은 현재 [Nyaa Chat Portable Client v1.0 (Open Custom Edition)] 사용 중입니다 🖥️
